# Perfil e preferências

Preencher com a pessoa (poucas perguntas de cada vez). Guardar como `perfil/perfil.md`.

```markdown
# Perfil de procura
- Nome:
- Cargos-alvo (por ordem de preferência):
- Nível: estágio / júnior / pleno / sénior / gestão
- Localização base:
- Remoto / híbrido / presencial:
- Aberto a relocação? Onde:
- Autorização de trabalho / restrições de visto (por país):
- Tipo de contrato: efetivo / prazo / consultoria / freelance
- Idiomas de trabalho:
- Setores preferidos:
- Setores/empresas a evitar:
- Expectativa salarial (opcional):
- Disponibilidade para começar:
- Pontos fortes a destacar:
- Pontos fracos / lacunas conhecidas:
- Contactos a incluir no CV (email, telefone, LinkedIn, portfólio):
- Fotografia no CV? (padrão: não, exceto se o mercado/anúncio exigir)
```

Usar este ficheiro para filtrar vagas e decidir tom e conteúdo dos documentos.
