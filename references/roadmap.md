# Roadmap (não implementar na v1)

Versões futuras previstas. Se a pessoa pedir algo daqui, explicar que ainda não está nesta versão e fazer a parte manual possível (ex.: preparar as respostas para colar).

- v1.4 (atual): + scan em massa sem LLM (`jh scan`), deduplicação, prefiltro e triagem em lote (inspirado em opt-career-ops).
- v1.2: procurar vagas, analisar fit, adaptar CV, documentos, revisão multi-agente com portão, README por vaga; Claude Code e OpenCode.
- v1.5 (próximo): avaliação A-G com nota 0-5 e bloco de legitimidade da vaga; follow-up com cadência; mensagens de contacto; análise de padrões de rejeição; banco de histórias STAR+R.
- v2: preencher formulários de candidatura (browser automatizado, ex.: Claude in Chrome ou um MCP de browser/Playwright) com revisão da pessoa antes de submeter; envio de email via Gmail com rascunho para aprovação.
- v3: monitorização periódica de novas vagas (tarefa agendada), alertas de prazos, follow-ups automáticos, preparação de entrevista com simulação.

Regra para qualquer versão futura: nunca submeter nada sem confirmação explícita da pessoa.
